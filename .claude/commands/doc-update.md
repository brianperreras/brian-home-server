# doc-update

Update or add content to a documentation chapter.

Usage: `/doc-update <chapter> <what to change>`

Steps:
1. Read the target chapter file in `docs/`.
2. Make the requested change — prefer editing existing sections over appending.
3. Ensure headings, table formatting, and numbered steps stay consistent with the rest of the file.
4. If the change affects the setup order or the chapter list, update `README.md` too.
5. Never create a new chapter file without asking first.

If no chapter is specified, ask which one before proceeding.
